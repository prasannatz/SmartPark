Project Overview

Micro Project — 03 | Smart Cities | CO1 & CO5

📦

Data Structure

Parking slots are stored in a linear array. Each element is a slot object with ID, status (free/occupied/reserved), vehicle plate, and timestamp.

slots[i] = { id, status, plate, time }
🔍

Searching (CO1)

Three search algorithms traverse the array: Linear Search (sequential), Binary Search (sorted array, halving), and Jump Search (block + linear).

⚙️

Sorting (CO5)

Five sort algorithms implemented from scratch: Bubble, Selection, Insertion (O(n²)) and Quick Sort, Merge Sort (O(n log n)) with swap & comparison counters.

📊

Performance Evaluation

Every operation records comparisons, swaps, steps, and execution time in microseconds. Benchmark mode runs all algorithms on the same dataset for a fair comparison.
